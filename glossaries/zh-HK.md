# 港式書面語詞表（zh-HK polish）

用於在 OpenCC `s2hk`（或同等簡→繁）之後，再套一層 **香港書面語** 用詞。  
機械轉換 ≠ 香港書面語；本表係 M0 最小人手表，可續加。

| 來源（簡／OpenCC 後常見） | 港式優先 | 備註 |
|---------------------------|----------|------|
| 会话／會話 | **對話** | UI「新對話」 |
| 设置／設置 | **設定** | Settings |
| 保存 | **儲存** | Save |
| 文件夹／文件夾／資料夾 | **檔案夾** | Folder |
| 文件（泛指） | **檔案** | 檔案名稱／選擇檔案 |
| 打开／打開 | **開啟** | Open |
| 关闭／關閉 | 關閉 | 已通用 |
| 搜索／搜索 | **搜尋** | Search |
| 默认／默認 | **預設** | Default |
| 侧边栏／側邊欄 | **側欄** | Sidebar |
| 登录／登錄 | **登入** | Sign in |
| 账户／賬戶 | **帳戶** | Account |
| 信息 | **資訊** | Info |
| 视频／視頻 | **影片** | Video |
| 加载／加載 | **載入** | Loading |
| 菜单／菜單 | **選單** | Menu |
| 软件／軟件 | 軟件 | OK |
| 网络／網絡 | 網絡 | OK |
| 完整访问／完整存取 | **完整存取** | Full access（參考社群港式包） |
| 确定／確定 | 確定 | OK |
| 取消 | 取消 | OK |
| 删除／刪除 | 刪除 | OK |
| 编辑／編輯 | 編輯 | OK |

產品專有名詞（Queue、Steer、JSON、API 等）可保留英文。
